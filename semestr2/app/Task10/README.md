# Zadanie 10

W pliku `semestr2/task10.php`:

1. Załaduj plik `vendor/autoload.php`
2. Zaimportuj klasy z `App\Task10\Product` i `App\Task10\Basket` używając `use`
3. Stwórz instancje klas i dodaj do koszyka kilka produktów
4. Dodaj obsługę `twig` i wyrenderuj szablon `semestr2/templates/task10/basket.html.twig`, który pokaże uproszczony widok koszyka:
   * lista produktów (nazwa i cena w formacie "9,99 zł")
   * suma w formacie "9,99 zł"
5. Uzupełnij pliki `semestr2/templates/task10/header.html.twig` i `semestr2/templates/task10/footer.html.twig` (dowolną treścią) i dołącz do widoku koszyka
6. Opcjonalnie dodaj style css
