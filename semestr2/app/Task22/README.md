# Zadanie 22

1. Stwórz moduł własny na sklepie, a następnie poniżej w sekcji Rozwiązanie wpisz nazwę modułu oraz link do strony sklepu na którym ten moduł został umieszczony.
2. Moduł powinien mieć: `TWIG`.
3. Moduł ten powinien być dostępny tylko na stronie produktu.
4. Używając zmiennych globalnych w Twig dla kontekstu [produktu](https://storefront.developers.shoper.pl/contexts/#product) pobierz [produkt](https://storefront.developers.shoper.pl/object-api/methods/get-product/) i wyświetl w h1 jego nazwę.
5. Pod nazwą wyświetl listę [powiązanych produktów](https://storefront.developers.shoper.pl/object-api/objects/products/product/#relatedproducts-property).
